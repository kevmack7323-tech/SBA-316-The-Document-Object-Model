'Interactive Portal Teleportation Project'(SBA 316)

I used DOM & BOM properties, methods, and techniques to create a web application that provides a dynamic user experience and a dynamic web application. In addition to implementing basic form validation using a combination of built-in HTML validation attributes and DOM-event-driven JavaScript validation.

The following requirements were met:

-DOM Manipulation: Styled wrappers and dynamic layout updates JavaScript.
-Event Listeners: Integrated click and mouseover events to modify user elements.
-Form Validation: Event-based loops to validate inputs dynamically before submission.
-Optimized Rendering: Implemented Document Fragment to stage UI modifications off-screen.
*BOM Features: Utilized window.alert and a timed setTimeout delay for Window.open navigation.

Programming Languages Utilized:
-HTML5
-CSS3 
-JavaScript
